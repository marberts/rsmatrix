# rsmatrix: Matrices for Repeat-Sales Price Indexes

Calculate the matrices in Shiller (1991,
[doi:10.1016/S1051-1377(05)80028-2](https://doi.org/10.1016/S1051-1377%2805%2980028-2)
) that serve as the foundation for many repeat-sales price indexes.
